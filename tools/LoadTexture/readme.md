# Load Texture Files to Apollo5 Board
if you want to load texture to your board, you can use this binary.
1. `make apollo510_evb` or `make apollo5b_eb_revb`
2. Connect the USB Type-C port on the right-bottom corner of EVB(not the J-Link port) to your PC
3. You should see a new movable disk appear in your File Explorer window.
   If not, please check your USB cable, or try another USB port.
4. Copy the texture files to this disk.
